> [!IMPORTANT]
> Этот репозиторий является модифицированной сборкой на базе проектов **zapret**, **zapret-win-bundle** и **zapret-discord-youtube**.

## 📌 О проекте

**DPI LAB Zapret** — Windows-сборка на базе Zapret с готовыми стратегиями для работы с DPI-фильтрацией.

Сборка использует `winws.exe` и драйвер **WinDivert** для обработки сетевого трафика и применения различных сетевых стратегий.

В комплект входят:

- несколько готовых `general*.bat`;
- `service.bat` для управления службой;
- списки доменов и IP;
- диагностические инструменты;
- инструменты тестирования стратегий.

Основные сценарии использования:

- Discord;
- YouTube;
- сайты и сервисы из пользовательских списков;
- тестирование разных DPI-стратегий;
- запуск выбранной стратегии вручную или через службу Windows.

## 💻 Системные требования

- Windows 10 / Windows 11;
- 64-битная система рекомендуется;
- права администратора для установки службы и работы WinDivert;
- рекомендуется распаковывать сборку в отдельную папку.

## 🚀 Быстрый запуск

1. Скачайте ZIP-архив из раздела **Releases**.
2. Полностью распакуйте архив.
3. Запустите `general.bat`.
4. Проверьте работу нужных сервисов.
5. Если текущая стратегия не подходит — закройте её и попробуйте другой `general*.bat`.
6. Когда найдёте подходящую стратегию, при необходимости установите её как службу через `service.bat`.

> [!TIP]
> Работоспособность конкретной стратегии зависит от сети, провайдера и текущей конфигурации DPI. Если одна стратегия не работает, попробуйте другую.

## 🔀 Выбор стратегии

В сборке присутствует несколько вариантов запуска, например:

```text
general.bat
general (ALT).bat
general (ALT2).bat
general (FAKE TLS AUTO).bat
general (SIMPLE FAKE).bat
```

Разные стратегии используют разные параметры обработки трафика.

Если базовый `general.bat` не подходит:

1. закройте текущее окно;
2. запустите другой вариант;
3. проверьте Discord, YouTube и нужные сайты;
4. выберите наиболее стабильную стратегию для вашей сети.

## ⚙️ `service.bat`

`service.bat` используется для управления сборкой и установленной службой Windows.

В зависимости от версии сборки через него могут быть доступны:

- установка выбранной стратегии как службы;
- удаление службы;
- проверка состояния;
- управление IPSet-фильтрацией;
- обновление списков;
- диагностика;
- тестирование стратегий.

### Установка стратегии как службы

Сначала убедитесь, что выбранный `general*.bat` работает корректно.

После этого запустите:

```text
service.bat
```

и выберите установку службы.

### Удаление службы

Если стратегия продолжает работать после закрытия окна, возможно, она была установлена как служба.

Используйте:

```text
service.bat → Remove Services
```

## 🛡️ WinDivert и антивирусы

Zapret использует **WinDivert** — драйвер, который работает с сетевым трафиком на низком уровне.

Из-за особенностей работы сетевых драйверов отдельные средства безопасности могут дополнительно проверять такие компоненты.

## 📝 Пользовательские списки

Для добавления собственных доменов используйте:

```text
lists/list-general-user.txt
```

Для исключений:

```text
lists/list-exclude-user.txt
lists/ipset-exclude-user.txt
```

После изменения списков перезапустите стратегию.

## 🧪 Диагностика

Если нужный сервис не работает:

1. попробуйте несколько `general*.bat`;
2. проверьте пользовательские списки;
3. временно закройте другие VPN, прокси и DPI-инструменты;
4. запустите диагностику через `service.bat`;
5. при наличии используйте `utils/test zapret.ps1`.

Одновременная работа нескольких программ, перехватывающих сетевой трафик, может приводить к конфликтам.

## ❓ Частые проблемы

### `general.bat` запускается, но сайт не работает

Попробуйте другую стратегию:

```text
general (ALT).bat
general (ALT2).bat
general (FAKE TLS AUTO).bat
general (SIMPLE FAKE).bat
```

Также проверьте, присутствует ли нужный домен в списках.

### Discord работает, а YouTube нет — или наоборот

Это может означать, что текущая стратегия подходит только для части трафика.

Попробуйте другую конфигурацию.

### После закрытия окна стратегия продолжает работать

Проверьте, не установлена ли она как служба Windows.

Удалить службу можно через:

```text
service.bat
```

### Есть конфликт с VPN или другим сетевым ПО

Закройте другие VPN, прокси, фильтры трафика и похожие утилиты, затем повторите проверку.
